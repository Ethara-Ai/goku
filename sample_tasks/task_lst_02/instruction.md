I have a collection of images of various types of animals that need to be segregated for my school project. Your task is to create three folders named animals, insects, and copies. Place all animal images in the animals folder, all insect images in the insects folder, and for any image that appears more than once, keep the image with the lowest numeric value in its filename in the animals or insects folder, and move all other duplicate copies to the copies folder. Then, inside the animals folder, create three subfolders titled feline, hooved, and others. The feline folder contains pictures of all felines, the hooved folder contains all animals with hooved feet, and the others folder should include pictures of all other animals. After completing the task, create a markdown file named ani.md documenting the data for each folder, including the count of pictures in each folder and subfolder, the count of lion cubs in all pictures, and a directory tree in markdown style.
